# Design System

Neutral salon placeholder palette, to be replaced with approved brand values:
- Ink: `#292522`
- Muted: `#756d67`
- Accent: `#b97868`
- Accent dark: `#8f564c`
- Surface: `#fffaf7`
- Border: `#eadfd9`

Typography uses system sans-serif. Layout uses a 1120px container, 8px spacing rhythm, 16px radius and restrained shadows. Interactive controls have visible focus styles and clear loading, error and success states.
